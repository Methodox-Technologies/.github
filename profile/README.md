# Divooka - the Visual Programming Platform

Hi there!👋

Divooka is a visual programming platform that enables people to use graphical building blocks to solve problems. Despite the simple look, it's quite advanced behind the scene. It started out (as Parcel) as a flowchart engine meant to make office life and data analytics easier with better visualization, and with a stretch - maybe even fun! These days it is a general-purpose programming system: data, pictures, sound, procedural worlds and small applications are all built the same way, as graphs of nodes. It complements the use of Excel, MATLAB/Python rather than trying to replace them.

From a technical perspective, Divooka is a lightweight general-purpose node-based programming system, with a high-level library of ready-made tools on top, built on C# and .NET. A graph can be dataflow, a step-by-step routine, a state machine, a declarative description or a type of your own, and one document can mix them. Divooka is situated between a Fourth generation language (4GL) and a Third generation language (3GL), meaning it operates on high level domain objects but is still largely algorithm based despite declarative features. Here is a video demo of an [early prototype in C# implemented using WPF (2022)](https://youtu.be/yEHaf_4y5AE). It's simple enough to be used by non-programmers but also extensive enough to be used by experienced developers. Its heart is still data analytics and automation, and it has grown well beyond them.

Divooka comes in two editions. **Divooka Explore** is the one for learning and exploring, with a fixed set of toolboxes and a free [demo](https://store.steampowered.com/app/4770820/Divooka_Explore_Demo/). **Divooka Compute** is the professional one: explicit package management, a compiled runtime, text-based documents that play well with version control, and command-line tools. The editor runs on Windows today, and macOS and Linux are planned.
