# Methodox Technologies, Inc.

Hi there! 👋

This organization holds the development of **Divooka**, a general-purpose visual programming system from Methodox Technologies, Inc. in Toronto. Divooka was previously known as Parcel, and the reference implementation repository still carries the name Parcel NExT.

Divooka programs are graphs of nodes. A graph can be dataflow, a step-by-step routine, a state machine, a declarative description or a type, and a document can mix them. Divooka comes in two editions: **Explore** for learning and exploring, and **Compute** for professional work, with package management, a compiled runtime and a command-line runner.
